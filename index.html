About the project

KanaPet started as a simple question: what if learning kana felt like taking care of something small? Instead of a streak counter that shouts at you, there is Mochi — a pet who practices alongside you, grows with your XP and reacts to how the session is going.

The learning model is deliberately narrow. Learn, Review and Progress tabs keep the loop short: see a character, hear it, answer honestly, come back to the ones you missed. The Kana tab is always one tap away when you want to browse the full chart.

It is built for phones first, runs entirely without a server, and contains no ads, analytics or sign-up. The Android app is a Capacitor wrapper around the same web code, so both versions behave identically.
