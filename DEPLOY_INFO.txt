-------

  `.nojekyll` present. No server, database or paid service is required.
  Google indexing: robots.txt + sitemap.xml are live. Submitting the sitemap
  in Google Search Console needs the owner's Google account (manual step).

TO DEPLOY NEXT TIME
-------------------
```bash
cd ~/Downloads/kana
cp "project files/kanapet/www/web-version.html" web-deploy/app.html
cp "project files/kanapet/www/index.html"        web-deploy/app-shell.html
cp "project files/kanapet/www/manifest.webmanifest" "project files/kanapet/www/sw.js" web-deploy/
rsync -a --delete "project files/kanapet/www/js/"    web-deploy/js/
rsync -a --delete "project files/kanapet/www/css/"   web-deploy/css/
rsync -a --delete "project files/kanapet/www/fonts/" web-deploy/fonts/
rsync -a --delete "project files/kanapet/www/icons/" web-deploy/icons/
rsync -a --delete "project files/kanapet/www/audio/" web-deploy/audio/
# re-apply deploy-only edits: sw.js CORE/fallback = app.html,
# manifest start_url = ./app.html, and KEEP index.html (landing) untouched.
cd web-deploy && git add -A && git commit -m "v<ver>: ..." && git push origin main
```
Then create a GitHub release and upload the APK as asset `KanaPet.apk` so the
web Download button resolves to the new version:
```bash
gh release create v<ver> /path/KanaPet.apk -R nahidsarker771/kana-pet \
  --title "KanaPet v<ver>" --notes "..."
```
