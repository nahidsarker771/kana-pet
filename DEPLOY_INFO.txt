-------------

    (natural female), Yuki (bright Nanami variant), Keita (natural male).
    1003 clips each; default Nanami; Profile cards select/preview.
  - Cute WebAudio pet emotion sounds (mew/chirp/purr/happy/sad/celebrate)
    with Profile "Pet sounds" toggle.
  - PWA cache bumped to kanapet-v1.23; audio subdirectory regex now caches
    nanami/yuki/keita clips on first play.
  - APK grew to ~48 MB (4 × 1003 audio clips bundled).
  - Bangla + English labels for voice actor / pet sounds.

TO DEPLOY NEXT TIME

```bash
cd ~/Downloads/kana
cp "project files/kanapet/www/web-version.html" web-deploy/index.html

git push origin main
```
Then create a GitHub release and upload the APK as asset `KanaPet.apk` so the
web Download button resolves to the new version.
